### How I use AI

> Modern test automation isn't just about writing test code. It's about deciding what deserves trust when machines build alongside us.

- **From acceptance criteria to test cases**: Claude turns them into scenarios ready to automate, including the edge cases that are easy to miss.
- **Review before trust**: every AI-generated test case is checked against the real requirements, which is also how I find gaps in coverage.
- **Writing and running tests**: Claude Code alongside Playwright, with Playwright MCP to drive the browser. I review and own every line.
- **Failures and bug reports**: AI reads the failure logs with me to reach the root cause faster, then helps draft clear bug reports.

### Projects

**[Vagalume](https://github.com/gabrielnecastro/vagalume-site)**: a fictional job board built as a practice target for software testers. Candidates apply to jobs, companies move applicants across a kanban board, and a small course store has a cart, coupons and checkout.

| Layer | What you can practice |
|---|---|
| UI | Shadow DOM, an iframe, drag and drop, a cookie banner, a broken image, and a `data-testid` on nearly every element |
| API | 60 documented operations in OpenAPI 3 with Swagger UI, ready for contract testing |
| Data | PostgreSQL 16 in Docker, so tests can check what the screen can't show |
| Failures | Checkout returns 502 about 15% of the time, an admin action fails about 35% of the time, rate-limited coupons, slow and flaky endpoints |
